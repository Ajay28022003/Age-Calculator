🎯 Purpose

The main goal of this project was to learn and practice the basics of web development —
how to structure a web page using HTML, style it using CSS, and make it interactive with JavaScript.

⚙️ Technologies Used

HTML – for creating the page structure

CSS – for styling and layout design

JavaScript – for date calculations and DOM manipulation

🌟 Features

Clean and simple user interface

Takes the user’s date of birth as input

Displays age in years, months, and days

Responsive layout with a colorful gradient background

🔧 How It Works

The user selects their Date of Birth using the date input field.

When the “Calculate” button is clicked, JavaScript takes the date and compares it with the current date.

It then calculates the difference and displays:

Total Years

Total Months

Total Days

The result updates instantly in the output section.

💡 What I Learned

How to create and style a webpage using HTML and CSS

How to use JavaScript’s Date object for date-related calculations

Handling user input and updating results dynamically using the DOM

Structuring small projects and linking multiple files (HTML, CSS, and JS)
